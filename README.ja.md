# 0rhxPlayer プラグインリポジトリ

[English](README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

**0rhxPlayer (0P)** 公式プラグイン配布・インデックスリポジトリ。

本リポジトリは GitHub Actions を通じて `index.md` カタログを自動管理しています。0rhxPlayer デスクトップアプリ内の「Plugins」マーケットが本カタログを読み込み、リアルタイム検索、カテゴリ別閲覧、ワンクリックインストールを提供します。

---

## ディレクトリ構成

各プラグインは機能カテゴリごとに分類されています：

---

0rhxPlayer-Plugin/
├── .github/workflows/
│   └── update-index.yml       # カタログ自動更新ワークフロー
├── NetService/                # クラウド音楽・オンラインメディアソース（網易雲、Subsonic、WebDAV など）
├── Lyrics/                    # オンライン歌詞・同期歌詞プロバイダ
├── Metadata/                  # カバーアート取得・タグ補完
├── DSP/                       # ネイティブ DSP 音響効果（リバーブ、コンプレッサーなど）
├── Test/                      # 検証・デバッグ用ダミープラグイン
│   └── gunmu.0px              # 動作確認用最小パッケージ
├── doc/                       # 開発者ガイドおよび API 仕様書（CI インデックス対象外）
├── index.md                   # 自動生成されるプラグイン総合目録
└── README.md

## 設計方針・アーキテクチャ

0rhxPlayer は**「WebView 不使用・レンダリング権はホストが保持」**という軽量かつ調和の取れた UI 哲学を徹底しています：

1. **ホストによる完全ネイティブ描画**: プラグイン内部での WebView 組み込みや自由描画は禁止されています。プラグインは構造化データスキーマのみを提供し、UI はすべて 0P 本体の Material 3 QML コンポーネントでネイティブに描画されます。
2. **サイドバー登録制限**: 1 つのプラグインが登録できるサイドバー項目は**最大 1 つ**です。登録された項目は 0P 本体のサイドバー編集・並び替え機能によって一元管理されます。
3. **グローバル Hook 対応**: サイドバー項目を持たずにグローバル検索やメディアライブラリを Hook することが可能です（例：ローカルファイルを持たずにクラウド音源のみで再生するストリーミング型プラグイン）。
4. **パッケージ形式（`.0px`）**: 標準の ZIP アーカイブ形式。ルートディレクトリに `plugin.json`（マニフェスト）および `main.js`（エントリポイント）を含む必要があります。

## 公式インデックスへの登録申請

1. 本リポジトリを Fork します。
2. パッケージ化した `.0px` ファイルを対応するカテゴリディレクトリに配置します（例：`NetService/CloudNetease_1.0.0.0px`）。
3. Pull Request を作成します。GitHub Actions によりマニフェスト検証および SHA256 チェックサムの算出が自動実行されます。
4. PR がマージされると、数分以内に全世界の 0rhxPlayer クライアントに反映されます。
